CHALOO BENGALURU – DEMO PROJECT
================================

FILES
- index.html, login.html, booking.html, seats.html, wallet.html,
  tickets.html, passes.html, services.html, help.html, admin.html
- css/style.css
- js/script.js

RUN IN VS CODE
1. Extract CHALOO-BENGALURU.zip.
2. Open the extracted CHALOO-BENGALURU folder in Visual Studio Code.
3. Install the "Live Server" extension if it is not already installed.
4. Right-click index.html and choose "Open with Live Server".
5. The site normally opens at http://127.0.0.1:5500/index.html.

IMPORTANT
This is a front-end academic demonstration. It uses browser LocalStorage,
not a server database. Demo login credentials are not secure. Bus routes,
schedules and fares are sample values, not live or official BMTC information.
Payments, pass approval, QR display and identity proof checks are simulated.
Do not enter real Aadhaar numbers, bank credentials, card details or UPI PINs.
For real deployment, implement a secure backend, database, authentication,
payment gateway, verified official transport data and authorized integrations.
